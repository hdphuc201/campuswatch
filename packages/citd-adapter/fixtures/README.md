# CITD fixtures (synthetic)

Every file here is **invented test data** written to resemble a typical Vietnamese student
portal. None of it was captured from the CITD Portal, and it contains no real names, student
IDs, grades, or amounts.

Before the pilot, a student must open each Portal page with their own account, save the page,
redact all personal values, and replace or extend these fixtures. Never commit an unredacted
page, a cookie, or a session token. See `docs/runbooks/citd-adapter.md`.
